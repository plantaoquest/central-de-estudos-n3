# Central de Estudos N3

Site de estudo para a prova N3 (SOI V, HAM V e IESC V, semanas 15, 16 e 17), em HTML, CSS e JavaScript, sem dependências.

Abra `index.html` pelo GitHub Pages. O progresso fica salvo no navegador; use **Fontes → Exportar backup** e **Restaurar backup** para levar o progresso entre aparelhos.

Os PDFs e slides das aulas não fazem parte deste repositório.
